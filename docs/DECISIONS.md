# Development Decisions

## Rules System
Decision:
Support D&D 2014, D&D 2024, and custom Bloodlines rules together.

Reason:
Keep the engine flexible and allow different campaign styles.

## Modular Architecture
Decision:
Separate engine logic, rules, and data.

Reason:
Allow expansion without rewriting core systems.

## AI Dungeon Master
Decision:
Build toward AI-driven narration and world interaction.

Reason:
Create a dynamic RPG experience instead of fixed encounters.

## GitHub Memory System
Decision:
Store project state and checkpoints in docs/.

Reason:
Allow fast resume between development sessions.
