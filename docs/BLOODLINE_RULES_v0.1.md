# BLOODLINES Bloodline System Rules Specification

## Data Structure

### Bloodline
- Bloodline ID
- Name
- Description
- Tiers
- Powers
- Unlock Conditions

### Bloodline Evolution Path
- Evolution Path ID
- Prerequisites
- Requirements
- Changes

### Awakening Mechanics
- Awakening Conditions
- Awakening Effects

### Mutations
- Mutation ID
- Trigger Conditions
- Effects

### Curses
- Curse ID
- Curse Effects
- Trade-Offs
- Expiry Conditions

### Blessings
- Blessing ID
- Effects
- Acquisition Conditions

### Legacy Quests
- Quest ID
- Objectives
- Rewards

## Engine Requirements

- Bloodline power unlocking
- Evolution checks
- Awakening triggers
- Curse and blessing management

## Tests

- Power unlocking
- Evolution paths
- Awakening
- Mutation/curse interactions
- Legacy quests
