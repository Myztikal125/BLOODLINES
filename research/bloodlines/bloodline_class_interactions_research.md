# Bloodline Class Interaction Research

## Goal
Design how inherited powers interact with character classes in BLOODLINES.

## Research Areas

### 1. Class Influence
How does a class change a bloodline?

Examples:
- Wizard + Shadowveil
- Fighter + Shadowveil
- Rogue + Shadowveil
- Cleric + Shadowveil

### 2. Bloodline Influence
How does a bloodline modify a class?

Examples:
- New abilities
- Modified spells
- Unique resources
- Alternate progression paths

### 3. Awakening System
How do bloodline powers unlock?

Questions:
- Level based?
- Story based?
- Choice based?
- Risk/reward?

### 4. Balance Rules
Prevent:
- Overpowered combinations
- Duplicate abilities
- Infinite scaling

### 5. Identity
How does BLOODLINES become different from normal D&D-style multiclassing?
